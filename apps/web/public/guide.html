Foundational Context

What Exactly Is BrandShield AI?

BrandShield AI is a pre-publication brand governance engine. Unlike post-publication monitoring tools that scan Twitter or websites after a crisis occurs, BrandShield operates at drafting time inside the copywriter’s, marketer’s, and AI agent’s workflow to ensure that nothing non-compliant, unapproved, or legally hazardous ever goes live.

"No Citation, No Flag" Gatekeeper

Generic LLMs hallucinate phantom rules. In BrandShield, the Verifier Gatekeeper Agent automatically drops any flag that cannot cite an exact clause in the active Brand Pack (e.g. Brand Glossary §1.1 or Fact f_pricing_001). If there's no citation, there is no flag. Period.

Intent Guard Semantic Safety

When fixing violations, generative AI often changes user intent or introduces new prohibited promises (like turning "the best" into "100% guaranteed returns"). The Intent Guard Engine analyzes semantic coherence and negations to ensure every suggestion is safe before presenting it to the user.

Brand Guard MCP Server

Native Model Context Protocol (MCP) server integration. External AI systems (Claude Desktop, Cursor, ChatGPT plugins, marketing scripts) can call check_content and lookup_fact to govern content drafts automatically.

The Problem We Solve

Why Does This Problem Exist & Why Now?

With generative AI, companies produce 100x more content across dozens of agencies, marketing teams, and regional offices. But brand guidelines remain static 80-page PDF documents that humans ignore and LLMs hallucinate over.

1. Regulatory Fines & Prohibited Financial Promises

In fintech, claiming "guaranteed returns", "risk-free deposit", or "100% safe money" violates RBI, SEBI, and FTC regulations. A single rogue LinkedIn post can trigger regulatory audits, license freezes, and severe statutory fines.

2. Outdated Claims & Factual Desynchronization

A marketing copywriter uses a ChatGPT prompt that quotes last quarter's pricing (e.g. ₹4,999/mo instead of ₹3,999/mo) or claims an SLA (99.9%) that was superseded. Customers sign contracts based on false promises, forcing legal concessions.

3. Brand Dilution & Trademark Casing Slippage

Writing "Novapay" instead of "NovaPay", using banned hyperbolic slang like "insane savings that will blow your mind!!", or disrespecting competitors erodes the enterprise trust that took years to cultivate.

4. WCAG 2.2 Accessibility Violations

Social images and banners generated with insufficient contrast ratios fail WCAG 2.2 AA standards (< 4.5:1), exposing brands to accessibility lawsuits and alienating visually impaired users.

Technical Foundations

The 13-Agent LangGraph Swarm

BrandShield replaces fragile monolithic prompt chains with a deterministic-first, LangGraph-orchestrated multi-agent pipeline. Each agent has an isolated responsibility and strict Pydantic contract.

Agent 01 Deterministic

Ingestion & Segmentation

Extracts text spans, sanitizes PII, calculates sentence boundaries, and normalizes unicode characters.

Agent 02 Context Profiler

Context & Audience Agent

Adjusts risk weights based on channel (LinkedIn, Press Release vs internal memo) and target audience (CFOs, retail).

Agent 03 0ms Matcher

Terminology Agent

Exact CamelCase and banned term detection using regex and phrase matcher trees (e.g. Novapay → NovaPay).

Agent 04 WCAG Math

Accessibility Agent

Calculates relative luminance contrast ratios (WCAG 2.2 AA target 4.5:1) and Flesch-Kincaid grade levels.

Agent 05 Hex Validator

Visual & Asset Agent

Validates hex colors against approved palette and checks logo clear-space buffer ratios.

Agent 06 Semantic LLM

Tone & Voice Agent

Catches unsubstantiated superlatives, hyperbole, and aggressive slang while enforcing measured confidence.

Agent 07 Fact Verifier

Claims & Facts Agent

Cross-references numerical, SLA, and pricing claims against verified enterprise facts in the Brand Pack.

Agent 08 Strategic Alignment

Messaging Alignment Agent

Flags deprecated product lines and guarantees messaging reinforces current strategic positioning.

Agent 09 The Gatekeeper

Verifier Critic Gate

THE "No citation, no flag" barrier. Kills uncited flags and hallucinated rules with 100% mathematical precision.

Agent 10 Diff Engine

Fix Agent

Synthesizes 2-3 tracked-change suggestions with editorial rationale and character offset tracking.

Agent 11 Safety Protocol

Intent Guard Engine

Blocks fix suggestions that introduce new ungrounded promises or invert negative constraints.

Agent 12 Scoring & Routing

Risk Router & Scorer

Computes 0-100 Governance Score and routes High Risk items exclusively to Legal Reviewers.

Agent 13 (Dual) Adaptive Intelligence

Guideline Clarifier & Compiler

13a. Guideline Compiler: Transforms raw text and PDF documentation into structured JSON rules with positive/negative examples.
13b. Guideline Clarifier: Analyzes telemetry from reviewer overrides to identify ambiguous rules and drafts clarified wording for Admin approval.
